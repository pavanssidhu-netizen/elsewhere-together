## Sim behaviour
- Remove TUTORIAL_ORDER. First interaction with any object emits a WORLD_CHANGED intro caption.
- `MOVE{tx,ty}` = one adjacent tile, reject if !canWalk; tick++; partner acts every 12 ticks and after each fork (deterministic). `INTERACT{objectId, choice?}` rejected unless in getNearbyInteractables from v2 grid pos. Fork objects resolve immediately with choice (default LET_GO). Anchors, terminal, stones also via INTERACT. Keep legacy commands working for old tests or update the tests.
- Choices are diegetic verbs (no modal): SELF = "keep it", ECHO = "send it across", LET_GO = "let it be". SELF must NOT be universally winning: some SELF picks undermine a later shared condition (e.g. greenhouse SELF drains water the partner needs; radio SELF hogs the signal so partner signal drops). ECHO = durable partner benefit at next partner tick + visible local disadvantage. LET_GO = seeded roll biased by causal preparations (e.g. related object examined first).
- Partner: no stepToward into the player's child node. Own lineage; SEEK only shortens distance via its own lineage/shared ancestors; REUNION (same node) only at final convergence. Emit PARTNER_TRACE for distant visible changes. Every actor node transition appends a JourneyStep.
- FADE: coherenceDebt rises per tick while drift>=80 or strain>=85; WARNING at 30/60/85 with an actionable hint (stones, terminal); FADE at 100 -> phase FADE, ending 'FADE'. Debt decays otherwise. One roll can never fade.
- Easter egg: interact radio mast when light==0 and signal<=0 and `stones` previously examined -> realm ALIEN (REALM event). Same main routes (never locks the goal); stones return you to TOWN.
- Restore must reject saves lacking `v2`.
